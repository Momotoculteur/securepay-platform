# Dossier de preuves

> Une affirmation sans preuve n'est pas recevable, ni à l'audit croisé, ni dans le Dossier écrit du Bloc 5 (MSPR 4.1). Chaque contrôle et chaque test de résistance doit laisser une trace horodatée ici.

## Convention de nommage

```text
AAAA-MM-JJ_HHMM_<scenario>.<ext>
```

Exemples :

```text
2026-11-16_1042_gitleaks-blocage-faux-secret.png
2026-11-17_0955_lynis-avant.dat
2026-11-18_1520_k6-stress-paliers.json
2026-11-19_1012_exp01-pod-kill-grafana.png
```

Les captures montrent l'horloge (barre système, horodatage Grafana ou sortie `date`) et la commande qui a produit le résultat. Pas de secret visible sur une capture.
